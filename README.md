# eliseclafreniere.github.io

## General 
This repository is for my personal website that I created for my ENVS 193DS course "choose your own assignment". 

## Data and File Information 

This repository holds different file types used to create this website. 
- **_quarto.yml:** organizes the navigation bar, theme, and title for my website 
- **style.css:** my custom theme inspired by a prior student, Bella Kormos', website
- **docs folder:** contains my images, htmls, resume.pdf, and projects folder
- **projects folder:** contains my projects htlms, midterm.pdf, and images 
- **extensions folder:** contains jmgirard folder utilized for pdf rendering
- **data folder:** contains my csv utilized for my interactive map
- **images folder:** contains my film photography images for the interactive map
